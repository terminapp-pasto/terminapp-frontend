# Bus photos

Save one photo per company here (they are read by `src/buses.ts`), with these exact names:

| Company | File name |
|---|---|
| Expreso Bolivariano | `expreso-bolivariano.jpg` |
| Transipiales | `transipiales.jpg` |
| Transandoná | `transandona.jpg` |
| Continental Bus | `continental-bus.jpg` |

- `.jpg` format, landscape (wider than tall), about 1200 × 500 pixels and under 300 KB.
- Use photos you took or have the company's permission for.
- If a photo is missing, the page shows a bus illustration instead.
